# Speech Studio v0.1.0

Primera release del repositorio. El tag incluye la app de Windows que está en `main`: Qwen3-TTS, perfiles de voz, transcripción con faster-whisper, catálogo de modelos, hotkey de lectura, bandeja, toasts en el idioma de Ajustes, el canal de subtítulos en vivo y el instalador Inno Setup.

El archivo adjunto es `SpeechStudio_0.1.0_Setup.exe`, generado en el CI de Windows. Lleva `speech-studio.exe`, el backend y `setup-env.ps1`. No lleva modelos ni `.venvs`.

The attached file is `SpeechStudio_0.1.0_Setup.exe`, built by Windows CI. It includes `speech-studio.exe`, the backend, and `setup-env.ps1`. It does not include models or `.venvs`.

## Aún no funciona

- **Subtítulos en vivo.** El selector de ventanas y el envío de audio al STT elegido están en el código. No se ha oído una captura WASAPI real, así que no está demostrado que Discord, Edge o WhatsApp se subtitulen.
- **XTTS v2.** Hay `xtts_worker.py`, `.venvs/xtts` y pesos locales. Una carga falló una vez por faltar `six`. Una síntesis real puede seguir en validación. `runtime_supported` sigue en true.
- **Parakeet, Moonshine y Fish Audio.** Están en el catálogo con `runtime_supported: false`. El único STT local que corre es faster-whisper.
- **Instalador.** `SpeechStudio_0.1.0_Setup.exe` existe. El 24 de noviembre de 2026 se ejecutó en silencio y quedó en `C:\Program Files (x86)\XYZ-Productions\Speech Studio`. `setup-env.ps1` salió con código 0 y creó `core`, `qwen`, `stt` y `xtts`. `/DIR` silencioso ignoró la ruta pedida. Hace falta `uv` y red. El MSI y el NSIS de `tauri build` no van en esta release y no instalan Python.
- **macOS y Linux.** El CI enlaza el shell de Linux y hace check en macOS. No hay AppImage, `.deb` ni bundle de macOS. La bandeja y los toasts están escritos y sin probar en esos escritorios.
- **Idiomas.** La interfaz solo está en inglés y español.
- **Licencia.** Hay un `LICENSE` propietario. Permite ver y evaluar el código. No permite redistribuir, vender ni usar el software en producción.
- **API local.** El endpoint OpenAI-compatible sigue apagado por defecto.

## What does not work yet

- Live captions are implemented and a real WASAPI session has not been heard.
- XTTS v2 has a worker, `.venvs/xtts`, and local weights. A load failed once because `six` was missing. Real synthesis may still be validating. `runtime_supported` stays true. Parakeet, Moonshine, and Fish Audio stay `runtime_supported: false`.
- A silent clean install of the Inno Setup package on 24 Nov 2026 landed in `C:\Program Files (x86)\XYZ-Productions\Speech Studio`. `setup-env.ps1` exited 0 and created the `.venvs`, including XTTS. A silent `/DIR` was ignored. It still needs `uv`. Tauri MSI and NSIS bundles do not install the Python workers.
- Linux CI builds the shell and macOS CI typechecks it. There is no AppImage, `.deb`, or macOS bundle. Tray and toasts for those desktops are untested.
- The UI is English and Spanish only.
- `LICENSE` is proprietary: viewing and evaluation are allowed. Redistribution, resale, and production use are not.
