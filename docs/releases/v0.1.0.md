# Speech Studio v0.1.0

Primera release del repositorio. El tag incluye la app de Windows que está en `main`: Qwen3-TTS, perfiles de voz, transcripción con faster-whisper, catálogo de modelos, hotkey de lectura, bandeja, toasts en el idioma de Ajustes, el canal de subtítulos en vivo y el instalador Inno Setup.

Esta release de GitHub no adjunta `speech-studio.exe` ni `SpeechStudio_0.1.0_Setup.exe`. Esos binarios se generan en local.

## Aún no funciona

- **Subtítulos en vivo.** El selector de ventanas y el envío de audio al STT elegido están en el código. No se ha oído una captura WASAPI real, así que no está demostrado que Discord, Edge o WhatsApp se subtitulen.
- **XTTS v2.** Aparece en el catálogo y en los perfiles. No hay `xtts_worker.py` ni entorno `.venvs/xtts`. Elegirlo no sintetiza.
- **Parakeet y Moonshine.** Están en el catálogo. El worker los rechaza. El único STT local que corre es faster-whisper.
- **Instalador.** `SpeechStudio_0.1.0_Setup.exe` compiló con el arte de xyz-installer y apunta a `C:\Program Files\XYZ-Productions\Speech Studio`. No se ha ejecutado en una instalación limpia. Al instalar hace falta `uv` y red para crear `core`, `qwen` y `stt`. No crea `xtts`. El MSI y el NSIS de `tauri build` no instalan Python.
- **macOS y Linux.** No hay binario. La bandeja (clic primario abre el menú; en macOS el icono va como plantilla) y los toasts (`notify-send`, `osascript`) están escritos y sin probar.
- **Idiomas.** La interfaz solo está en inglés y español.
- **Licencia.** Hay un `LICENSE` propietario. Permite ver y evaluar el código. No permite redistribuir, vender ni usar el software en producción.
- **API local.** El endpoint OpenAI-compatible sigue apagado por defecto.

## What does not work yet

- Live captions are implemented and a real WASAPI session has not been heard.
- XTTS v2, Parakeet, and Moonshine are catalog entries. They do not run.
- The Inno Setup installer is compiled and has not been run on a clean machine. It needs `uv` and does not create the XTTS environment. Tauri MSI and NSIS bundles do not install the Python workers.
- macOS and Linux are not built. Tray and toasts for those systems are source-only.
- The UI is English and Spanish only.
- `LICENSE` is proprietary: viewing and evaluation are allowed. Redistribution, resale, and production use are not.
- This GitHub release does not attach the Windows executable or the setup program.
