# Speech Studio v0.2.1

Windows x64 desktop release (`SpeechStudio_0.2.1_Setup.exe`). Linux and macOS still build the shell from source; Live Captions capture, UI Automation, and this installer stay Windows-only.

## Fixes

- **Fish Speech 1.5** follows the model selected in Synthesize. A voice profile tagged Chatterbox (or another clone engine) only supplies the reference clip. It no longer fails with `Engine 'chatterbox' is not connected`.
- Fish Speech is a Python worker. The catalog no longer marks it ready just because the CrispASR binary is present.
- Live Captions can transcribe with an installed CrispASR STT model (Parakeet, Moonshine, Whisper, and the other compiled STT backends) instead of always proxying the Python faster-whisper worker.
- WASAPI process loopback retries initialization, connects to the captions socket with a timeout, and returns as soon as the capture thread starts.
- Quit no longer waits forever if WebView2 or COM teardown stalls.
- The Live Captions window opens centered on the bottom of the primary monitor and stays on top.
- The application picker is a body portal: Escape and the backdrop close it, and it is no longer clipped by the subtitles card.

## Added

- **Windows SAPI 5 / Loquendo** catalog engine. It lists installed 32-bit, 64-bit, and OneCore voices, including regional dialects, and can rescan from Models.
