# Speech Studio v0.2.2

## Actualizaciones

- El límite de descarga admite el instalador publicado, que superaba los 512 MiB.
- Verificación de tamaño y SHA-256 cuando GitHub proporciona la huella del asset.
- Selección de arquitectura en paquetes identificados como x64 o ARM64.
- Progreso de descarga, cancelación, limpieza de archivos incompletos y exclusión de instalaciones simultáneas.
- Los paquetes MSI se ejecutan mediante Windows Installer.

## Fiabilidad

- Rutas internas HTTP y WebSocket restringidas al escritorio local y orígenes de confianza.
- Escritura atómica de ajustes, historial y perfiles. Operaciones concurrentes de historial y perfiles serializadas.
- Arranque con timeout efectivo y drenaje de logs. Resolución por worker durante actualizaciones parciales de runtimes.
- Corrección de voces nativas sin perfil clonado en la API compatible con OpenAI.
- Corrección de estados de inicio y listeners de subtítulos. Los errores de conexión aparecen en la vista y el overlay.
- Seguimiento de foco iniciado con la aplicación y ventana redimensionable.

## Loquendo

Tarjeta propia en Models y Featured. En Windows permite detectar voces Loquendo instaladas y ejecutar un instalador local con confirmación. La descarga del pack queda pendiente de disponer de una fuente y licencia de redistribución verificables. El adaptador SAPI actual funciona en Windows.

## Instalación

El instalador de Windows incluye su intérprete y dependencias del núcleo. La construcción usa uv en el equipo de desarrollo. El equipo de destino puede ejecutar el núcleo y CrispASR sin instalar Python ni uv. Los motores Python adicionales todavía requieren un paquete opcional que se preparará en la siguiente etapa.

La validación de escritorio, subtítulos y atajo en macOS está pendiente de un equipo de prueba. Las compilaciones de Linux y macOS se identificarán por plataforma y arquitectura cuando sus paquetes estén disponibles.

## Paquetes de prueba verificados

- Windows Setup de 94.079.200 bytes. Instalación portable aislada con código 0. El ejecutable instalado coincide por SHA-256 con el build de producción. Backend 0.2.2 y síntesis CPU comprobados con Python y uv fuera de PATH.
- Paquete Debian amd64 de 261.971.834 bytes, construido en Debian mediante WSL. Runtime extraído del paquete comprobado mediante arranque del backend 0.2.2 y síntesis CPU. La compatibilidad de escritorio en otras distribuciones sigue pendiente.
- 108 pruebas Python y 18 pruebas Rust correctas en Windows. TypeScript y Vite compilados. Pruebas específicas de Update cubren integridad, arquitectura, cancelación y lanzamiento independiente del instalador.
- macOS dispone de workflow para Apple Silicon e Intel. El DMG sigue pendiente de compilación en los runners. La publicación y el recorrido completo de actualización desde una release nueva siguen pendientes.
- Las huellas de los archivos locales están en `installer/Output/SHA256SUMS.txt`. La validación gráfica de Windows y Linux sigue pendiente. Los datos de prueba se han mantenido separados de los datos del usuario.
