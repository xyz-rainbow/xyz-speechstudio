# Speech Studio v0.2.0

Desktop release for Windows x64 by **Rainbow Technology** (`SpeechStudio_0.2.0_Setup.exe`, bundled with CrispASR CUDA + CPU binaries).

## Highlights

### Engines & Persistent VRAM
- **Persistent CrispASR `--server` VRAM mode**: C++ / CUDA TTS models stay loaded in VRAM across Play chunks and successive generations (`Eject` unloads cleanly; `POST /api/tts/cancel` interrupts active synthesis; `--no-spoken-disclaimer` with `--accept-marking-responsibility`; CLI `-l <lang>` language propagation).
- **10 Verified Local TTS Engines** (validated end-to-end with real audio synthesis and NVIDIA Parakeet transcription):
  - **CrispASR native (C++ / CUDA)**: `Qwen3-TTS 1.7B`, `Kokoro 82M` (all 54 voices auto-packed to GGUF v3), `Piper`, `Chatterbox Turbo`, `CosyVoice3 0.5B` (+ `Chatterbox Multilingual` added to catalog).
  - **Unified `.venvs/pytts` Python environment**: `Coqui XTTS v2`, `F5-TTS Spanish` (`F5TTS_Base` architecture + automatic `<=11s` reference clip & transcript matching), `Fish Speech 1.5` (`v1.5.1`), `KittenTTS 2 Mini` (direct ONNX + multilingual `voices_<lang>.npz`).
  - **Native CPU**: real `eSpeak NG` formant synthesis via `espeakng-loader` (`espeak-ng.dll` / `ctypes`).
- Per-model **`CrispASR | Python`** runtime selector on dual-runtime cards (`Qwen3-TTS`, `F5-TTS`) in `ModelsView`.

### Synthesize, Profiles & UI/UX
- **Shared loading/player slot**: loading indicator swaps cleanly into `<ChunkedAudioPlayer>` as soon as chunk 0 is ready.
- **Play -> Stop control**: transforms into a red/rose animated **Stop** button while loading/synthesizing and cancels backend generation.
- **Floating Playback Island**: dedicated lime breathing border glow + 3-bar equalizer distinct from the update ring.
- **Reference audio workflow**: automatic non-destructive 24 kHz mono WAV normalization, inline reference audio preview, `>15s` warning badge + non-destructive **Trim to 12s** button, per-engine profile counters `(0)/(1)`, and automatic `Ready` status for inline clone engines.
- **Cleaner UI & notifications**: removed redundant `(CrispASR)` badges in Featured/Profiles and top tab headers; download toast alerts limited to start (`0%`) and completion (`100%`).
- **Live Captions & Window UX**: fixed `880x580` non-resizable window, persistent tab state across views, explicit clear (`x`) buttons, and crash-free Live Captions window enumeration (`spawn_blocking` + `IsHungAppWindow` guard + WASAPI PCM `WAVEFORMATEX`).

### Installer (Windows x64)
- Rebranded publisher & default path to **Rainbow Technology** (`C:\Program Files\Rainbow Technology\Speech Studio`).
- Hidden setup environment window (`runhidden` + `-WindowStyle Hidden`) bootstrapping unified `core` and `pytts` environments via `uv`.
