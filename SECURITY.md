## Reporting a vulnerability / Cómo informar de una vulnerabilidad

Please **do not** open a public issue, discussion, or pull request for a security vulnerability.

Report it privately through GitHub Security advisories:

https://github.com/xyz-rainbow/xyz-speechstudio/security/advisories/new

Include enough detail to reproduce the problem (affected version or commit, environment, and steps). Do not attach real API keys, tokens, or private recordings.

You should receive an acknowledgement when a maintainer sees the report. If the issue is confirmed, a fix will be prepared and credited as you prefer. If it is out of scope or not a vulnerability, you will be told why.
